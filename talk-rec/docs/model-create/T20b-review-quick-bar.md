# T20b 영상 빠른 검토 막대

- 카드를 누르면 현재 영상 테두리가 강조된다. 처음과 필터 변경 시에는 목록의 첫 미검토 영상을 선택한다.
- 하단 고정 막대에 제목·길이, 큰 영상 열기·승인·거절·보류 버튼, 코멘트와 남은 미검토 수를 모았다. 카드에도 큰 영상 열기 버튼을 두고 기존 정보와 설명을 표시한다.
- 판정과 코멘트를 함께 저장한 뒤 현재 목록의 다음 미검토 영상으로 이동한다. 끝에서는 앞쪽 미검토를 찾는다. 미검토 필터에서는 다음 카드를 먼저 선택·스크롤하고 목록을 갱신한 뒤 위치를 다시 맞춘다.
- 코멘트 초안은 영상을 오가도 유지한다. Enter는 기존 판정을 유지하며 코멘트를 저장한다. 미검토 영상의 코멘트는 첫 판정과 함께 저장한다. 저장 실패 시 현재 영상과 초안을 유지한다.
- 375px용 막대는 정보·입력·이동과 판정 버튼의 두 줄 그리드다. 입력칸은 포커스 시 넓어지고, 본문 아래 여백은 막대 높이에 맞춰 갱신한다.

단축키: **O** 영상 열기(새 탭), **A/R/H** 승인/거절/보류, **←/K** 이전, **→/J** 다음, **C** 코멘트, 입력칸의 **Enter** 코멘트 저장. 입력 및 한글 조합 중에는 판정·이동 단축키가 멈춘다.

검증:

- `.\.venv\Scripts\python.exe -m pytest tests/test_review.py --basetemp .local/pytest-t20b -p no:cacheprovider -q` → **29 passed**. 기존 API 테스트와 고정 막대·영상 열기·단축키·모바일 배치 문자열 검사를 포함한다.
- Node 합성 DOM 검사 통과: 현재 영상 선택, 초안 유지, 입력 중 단축키 차단, O, 저장 후 이동과 목록 갱신 순서, 저장 실패 복구, 빈 목록, Enter 코멘트 저장.
- 실제 브라우저의 375px 렌더링 검사는 GPU 프로세스 오류와 실행 시간 초과로 완료하지 못했다. 두 줄 구성과 가로 넘침 방지는 CSS 구현·문자열 확인까지 진행했다.
