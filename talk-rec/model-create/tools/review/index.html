사람 검토 현황

현황은 자동 제외 영상을 포함한 매니페스트 전체 기준입니다. 진행률은 이 콘솔에 표시할 수 있는 받은 영상과 후보 기준입니다. dev·test는 각각 사람 승인 채널 10개가 목표입니다.

사전 의견은 사람 승인이 아닙니다. 사람 승인 판정은 학습 반영의 기준이며, 실제 학습 진입 제한은 T21과 후속 파이프라인에서 적용합니다. 자동 제외 영상은 이 목록에 표시되지 않습니다.
