# 라벨 기준 v2

"남길 만한 순간" 판정 모델의 학습·평가 라벨을 다는 기준이다. 사람 라벨러와 LLM 라벨러가 같은 문서를 쓴다. 설계 배경은 [DESIGN.md](DESIGN.md) §3~4에 있다. 예문은 모두 이 문서를 위해 새로 쓴 것이다.

v1(발화마다 이야기 점수)과 달리 **묶음 하나에 라벨 하나**를 단다. 남기는 것이 텍스트가 아니라 그 구간의 음성이기 때문이다.

## 1. 무엇에 라벨을 다는가

- **단위는 대화 묶음이다.** 이어지는 발화 몇 개에서 열몇 개, 길어야 1분 30초쯤 되는 구간이다.
- **묻는 것은 하나다.** "이 가족이 한 달 뒤, 일 년 뒤에 이 구간의 **소리를 다시 들으면** 반가울까?"
- **완결된 이야기일 필요가 없다.** 실제 차 안 대화는 말이 툭 튀어나오고 주제가 금방 바뀐다. 아이의 한마디, 같이 터진 웃음, 지나가며 나온 옛날 얘기 한 줄이면 충분하다.
- **묶음 전체를 보고 판정한다.** 앞문맥(직전 묶음의 마지막 두 턴)은 무슨 얘기 중이었는지 이해하는 데만 쓴다.
- **전사는 틀릴 수 있다.** 단어 몇 개가 이상해도 무슨 상황인지 짐작되면 그대로 판정한다. 전사에 없는 내용을 지어내지는 않는다. 화자 표시가 없으므로 누가 말했는지 단정하지 않는다.

## 2. 판정 순서

1. **방송 멘트나 내레이션인가** → 맞으면 `skip`(§6)을 달고 끝낸다.
2. **남겨도 되는가** → 아니면 `exclude`(§5)를 단다. 여러 개 달 수 있다.
3. **남길 만한가** → `keep` 0·1·2(§3)를 단다. `exclude`가 있어도 `keep`은 내용대로 단다.
4. **어떤 상황인가** → `tags`(§4)를 단다.

## 3. `keep`

| 값 | 뜻 | 이런 묶음 |
| ---: | --- | --- |
| 0 | 남기지 않는다 | 길 안내와 운전 조율("다음에서 빠져", "주유하고 가자"), 일정·준비물 확인, 뉴스·연예인·남 얘기, 뜻 없는 소리, 기기 명령, 한두 마디로 끝난 맞장구 |
| 1 | 애매하다 | 이 사람들의 얘기이긴 한데 내용이 얇다. 반응은 있는데 무엇에 대한 것인지 알기 어렵다. 다시 들으면 "뭐였지?" 싶을 구간 |
| 2 | 남긴다 | 이 사람들만의 순간이 들린다. 겪은 일을 꺼내는 말, 눈앞의 일에 터진 반응, 아이의 말, 서로에게 건넨 마음, 같이 한 약속 |

가르는 질문은 세 가지다.

- **이 사람들만의 것인가.** 누구 차에서 나와도 똑같을 말이면 0이다. "요즘 기름값 비싸다"는 0, "아빠 차는 맨날 기름 경고등 켜고 다니잖아"는 이 가족의 얘기다.
- **다시 듣고 싶은 소리가 있는가.** 웃음, 감탄, 아이 목소리, 노래를 같이 부르는 소리는 내용이 얇아도 값지다.
- **한 구간으로 들어도 무슨 순간인지 알 수 있는가.** 알 수 있으면 2, 긴가민가하면 1이다.

묶음의 일부만 해당해도 된다. 길 안내 얘기 사이에 아이가 "아빠, 구름이 솜사탕 같아" 한 줄이 끼어 있으면 2다. 구간을 다듬는 일은 저장 단계가 한다.

**1을 아끼지 않는다.** 0과 2 사이에서 망설여지면 1을 준다. 1이 얼마나 나오는지, 어떤 묶음이 1인지가 이후 정책을 정하는 자료다.

## 4. `tags` 상황 태그

`keep`이 2이면 하나 이상 단다. 1이면 해당하는 것이 있을 때만 단다. 0이면 달지 않는다. 겹치면 모두 단다.

| 값 | 뜻 | 예 |
| --- | --- | --- |
| `recall` 옛날 얘기 | 탑승자가 직접 겪은 지난 일을 꺼낸다 | "여기 작년에 길 잘못 들어서 노을 봤던 데잖아" |
| `fun` 웃음·장난 | 같이 웃거나 놀리거나 장난치는 구간 | 엉뚱한 대답에 다 같이 웃음이 터진다 |
| `kid` 아이의 말 | 아이가 한 말, 아이의 엉뚱한 질문과 대답, 아이의 처음 | "엄마, 터널은 왜 깜깜해?" |
| `scenery` 풍경·감탄 | 눈앞의 것에 대한 감탄과 놀람 | "와, 바다다! 저기 봐, 진짜 파래" |
| `plan` 계획·약속 | 함께할 앞날에 대한 약속과 바람. 당장의 일정은 아니다 | "다음엔 할머니도 꼭 같이 오자" |
| `family_news` 가족 소식 | 가족·가까운 사람의 근황, 취향, 변화 | "언니 다음 달에 이사한대", "아빠는 회 못 먹잖아" |
| `heart` 고민·속마음 | 고마움·미안함·걱정·속내를 털어놓는다 | "아까 말없이 기다려 줘서 고마웠어" |
| `song` 노래·흥얼거림 | 같이 노래를 부르거나 흥얼거린다 | 아이가 동요를 부르고 어른이 따라 부른다 |

- **`family_news`만 있는 묶음**은 보통 `keep` 1이다. 근황이 반응이나 사연과 함께 나오면 2다.
- **`song`과 `external`을 가른다.** 탑승자가 부르는 소리는 `song`이다. 스피커에서 나오는 노래 가사만 전사된 것은 `external`이다.
- **`kid`는 아이의 말이 실제로 보일 때만** 단다. 어른이 아이 얘기를 하는 것은 `recall`이나 `family_news`다.

## 5. `exclude` 남기면 안 되는 사유

하나라도 달리면 저장하지 않는다. `keep`과 무관하게 단다.

| 값 | 뜻 | 예 |
| --- | --- | --- |
| `optout` | 기록을 원치 않는다는 말이 있다 | "이 얘긴 남기지 말자", "지금 건 녹음하지 마" |
| `sensitive` | 건강(진단·검사·치료), 돈(빚·급여·대출), 다툼과 가족 갈등, 제3자 험담, 식별정보(주소·번호·비밀번호), 성적 내용이 묶음의 중심이다 | "엄마 검사 결과가 나왔대" |
| `command` | 묶음이 기기 호출과 명령, 검색어·주소 불러 주기로만 이루어져 있다 | "글레오, 집으로 안내해 줘" |
| `external` | 탑승자의 말이 아닌 소리가 묶음의 대부분이다. 라디오·팟캐스트·영상, 내비 안내, 스피커폰 상대, 스피커의 노래 가사 | 라디오 사연이 길게 전사된 묶음 |
| `garbled` | 전사가 무너져 무슨 상황인지 짐작할 수 없다 | 뜻이 이어지지 않는 조각만 있다 |

- **묶음의 중심이 무엇인지로 판단한다.** 대화 중에 명령 한 줄, 내비 안내 한 줄이 끼어든 것은 `command`·`external`이 아니다. 그 줄을 빼는 일은 저장 단계가 한다.
- **`sensitive`의 경계**: 가벼운 컨디션("오늘 좀 피곤하다")이나 일상적 지출("주차비 삼천 원")은 해당하지 않는다. 다투는 중인 묶음은 내용과 무관하게 해당한다.
- **`optout`은 그 말이 들어 있는 묶음에 단다.** 앞서 저장한 구간까지 지우는 일은 저장 단계가 한다.
- **`garbled`를 아낀다.** 단어 몇 개가 틀린 정도로는 달지 않는다.

## 6. `skip` — 차 안 대화가 아닌 것

유튜브 영상에만 있는 말은 학습에서 뺀다. `skip: true`를 달고 `keep` 0, 나머지는 빈 값으로 둔다.

- 시청자 인사, 구독·좋아요 요청, 영상 소개와 마무리, 광고·협찬 낭독.
- 편집 과정에서 덧붙인 내레이션, 자막 낭독, TTS 음성.
- 묶음의 절반 이상이 위에 해당하면 `skip`이다. 진행 멘트 한 줄이 끼어든 대화 묶음은 `skip`하지 않는다.
- 카메라를 향해 말하더라도 동승자와 주고받는 대화면 `skip`하지 않는다.

## 7. 경계 사례

| 묶음의 내용 | 라벨 | 이유 |
| --- | --- | --- |
| 어디서 빠질지, 몇 시에 도착할지만 주고받는다 | `keep` 0 | 운전 조율이다 |
| 길 얘기 중에 아이가 "터널은 왜 깜깜해?" 묻고 어른이 웃으며 답한다 | `keep` 2, `kid`·`fun` | 일부만 해당해도 남긴다 |
| "저 휴게소 기억나?" "어, 거기" 하고 끝난다 | `keep` 1, `recall` | 꺼내기만 하고 내용이 없다 |
| "저 휴게소에서 비 와서 차에서 못 내렸잖아" "맞아, 그때 컵라면 차에서 먹었지" | `keep` 2, `recall` | 겪은 일의 내용이 있다 |
| "와" "우와" 하는 감탄만 있고 무엇을 보는지 알 수 없다 | `keep` 1, `scenery` | 반응은 있으나 대상을 모른다 |
| "와, 저 산 좀 봐. 눈 덮인 거 처음 봐" | `keep` 2, `scenery` | 반응과 대상이 함께 있다 |
| 연예인 결혼 소식에 대해 길게 얘기한다 | `keep` 0 | 재미있어도 이 사람들의 일이 아니다 |
| 연예인 얘기를 하다가 "너 어릴 때 그 가수 흉내 냈잖아" 하며 웃는다 | `keep` 2, `recall`·`fun` | 이 가족의 일로 넘어왔다 |
| "언니 다음 달에 이사한대" "어디로?" "수원" | `keep` 1, `family_news` | 근황 전달이고 얇다 |
| "엄마 요즘 무릎 괜찮아?" "많이 나았어, 네가 사 준 보호대 덕분이야" | `keep` 2, `family_news`·`heart` | 근황에 마음이 실렸다 |
| "아빠가 예전에 사업 접고 우리 이사 다녔잖아. 그때 네가 전학 가기 싫다고 울었지" | `keep` 2, `recall`, `exclude` `sensitive` | 남길 만하지만 금전·가정사가 중심이다 |
| 목소리가 높아지며 서로를 탓한다 | `keep` 0, `exclude` `sensitive` | 다툼이다 |
| "이건 녹음 안 됐으면 좋겠는데" 하고 얘기를 이어 간다 | 내용대로 `keep`, `exclude` `optout` | 기록 거부가 있다 |
| "글레오, 볼륨 줄여 줘" "에어컨 22도" | `keep` 0, `exclude` `command` | 명령뿐이다 |
| 대화 중에 "삼백 미터 앞 우회전입니다" 한 줄이 끼어 있다 | 대화 내용대로 | 한 줄 끼어든 것은 `external`이 아니다 |
| 라디오 진행자의 말이 길게 이어진다 | `keep` 0, `exclude` `external` | 탑승자의 말이 아니다 |
| 아이가 동요를 부르고 어른이 따라 부르다 웃는다 | `keep` 2, `song`·`kid`·`fun` | 다시 듣고 싶은 소리다 |
| "수고했어, 운전하느라" "아니야" | `keep` 1, `heart` | 마음은 있으나 짧고 흔하다 |
| "나 사실 그날 화낸 거 계속 미안했어" "나도 그랬어" | `keep` 2, `heart` | 속마음을 주고받는다 |
| "우리 결혼 십 주년엔 이 길 다시 오자" | `keep` 2, `plan` | 함께할 앞날의 약속이다 |
| "내일 세 시에 출발하자" "짐은 오늘 싸 놔" | `keep` 0 | 당장의 일정이다 |
| "여러분 오늘은 강릉에 가 볼 건데요, 구독 좋아요 부탁드려요" | `skip` | 방송 멘트다 |
| 화면 설명을 읽어 주는 내레이션이 이어진다 | `skip` | 차 안 대화가 아니다 |

## 8. 자주 하는 실수

- **이야기가 완결돼야 남긴다고 생각하기.** 한 줄짜리 순간도 남긴다.
- **말투로 판정하기.** "~잖아", "기억나?"가 있다고 2가 아니다. 반대로 담담한 말투여도 내용이 있으면 2다.
- **감정 단어만 보고 올리기.** "짜증 나, 또 막혀"는 교통 상황에 대한 말이라 0이다.
- **재미있는 화제를 남기기.** 뉴스와 남의 얘기는 재미있어도 0이다.
- **`exclude`가 있다고 `keep`을 낮추기.** 두 판단은 따로 한다.
- **전사가 조금 이상하다고 `garbled` 달기.** 상황이 짐작되면 내용대로 판정한다.
- **망설이다 0이나 2로 몰기.** 애매하면 1이다.

## 9. 출력 형식

묶음 하나에 한 줄이다. `note`에는 판정 근거를 한 문장으로 적는다. 본문 인용은 넣지 않는다.

```json
{"id":"yt:VIDEO_ID@12","keep":2,"tags":["kid","fun"],"exclude":[],"skip":false,"labeler":"human:이름","note":"길 얘기 중 아이의 엉뚱한 질문에 웃음"}
```

- `id`는 `{source}@{묶음 번호}`다.
- `keep` 2에는 `tags`가 하나 이상 있어야 한다. `keep` 0에는 `tags`가 없다.
- `skip`이 참이면 `keep`은 0, `tags`와 `exclude`는 빈 배열이다.
