# 라벨 기준 v3

[설계안 v3](DESIGN.md)의 라벨을 다는 기준이다. 세 곳에서 같은 기준을 쓴다: 합성 장면 카드의 라벨 정의, 사람이 실제 묶음을 듣고 하는 판정, 큰 모델(Gemini)의 기준선 판정. 이 문서의 대화 예는 전부 지어낸 것이다.

v2의 `keep` 0·1·2, 태그 8종, `sensitive`·`garbled`·`skip`은 쓰지 않는다.

## 1. 무엇에 라벨을 다는가

**묶음** 하나에 단다. 묶음은 침묵 20초 또는 길이 90초에서 닫힌 대화 구간이다. 판정은 그 묶음 안에서 오간 것만으로 한다.

- **실제 묶음**: 음성을 듣고 단다. 전사 글은 참고로만 본다. 전사가 틀려도 실제로 오간 대화로 판정한다.
- **합성 묶음**: 카드가 라벨을 정한다. 사람은 깨끗한 원본 대화를 보고 그 라벨이 말이 되는지만 확인한다.

## 2. 판정 순서

1. **차 안 탑승자의 대화인가.** 아니면(방송 멘트, 내레이션, 스피커 소리뿐) `none`이고 메모에 "차 안 아님"을 적는다.
2. **가족의 대화인가.** 친구·동료처럼 가족이 아닌 사람끼리의 대화면 내용과 상관없이 `none`이고 메모에 "가족 아님"을 적는다. 동반차는 가족의 추억을 남기는 앱이다(2026-11-12 결정). 부부와 어른 가족은 가족으로 본다.
3. **나중에 다시 보고 싶지 않을 분위기인가.** 다투거나, 혼내거나, 안 좋은 얘기가 중심이면 `none`이고 메모에 "부정"을 적는다(§5).
4. **남길 것이 있는가.** 묶음 안 어디든 이야기나 한 줄 순간이 있으면 `keep`, 없으면 `none`.
5. `keep`이면 **`kind`**를 고른다: 이야기가 있으면 `story`, 한 줄 순간만 있으면 `moment`.
6. 판단이 갈리면 가장 가까운 쪽을 고르고 **`unsure`**를 켠다.
7. 기록 거부·기기 명령·스피커 소리는 **`policy`**에 따로 단다(§7).

## 3. `keep` — 남길 것

### `story` 이야기

**누군가 화제를 꺼내고, 다른 사람이 받아서, 그 화제로 두세 번 이상 오간다.** 완결될 필요가 없다. 길 필요도 없다.

- 아이가 오늘 있었던 일을 늘어놓고 부모가 되묻는다.
- 창밖을 보다가 같이 겪은 일을 서로 떠올린다.
- 둘 중 하나 고르기를 하며 이유를 주고받는다.
- 아이의 "왜?"에 어른이 답하고 아이가 다시 묻는다.
- 단답으로 시작했다가 좋아하는 것 얘기로 길어진다.

판단의 핵심은 **받아 주는 사람이 있고 화제가 이어지는가**다. 줄 수나 길이로 판단하지 않는다.

> "어 저기 만두 가게 아직도 있네" / "어디?" / "예전에 비 올 때 아빠랑 뛰어가서 샀잖아" / "맞다 그때 네 신발 다 젖었지" — 네 줄이지만 `story`다.

### `moment` 한 줄 순간

**이어지지 않아도 그 한마디·웃음·노래·감탄 자체가 남길 만하다.**

- 아이가 어른이나 내비 말투를 흉내 내고 다들 웃는다.
- 즉석에서 지은 노래 한 소절.
- 터널을 나오자 바다가 보여 다 같이 감탄한다.
- 짧은 놀림과 받아치기 한 번.
- 지루한 용무 얘기 한가운데 아이의 엉뚱한 한마디에 웃고 다시 용무로 돌아간다.

## 4. `none` — 없음

남길 화제도 한마디도 없다. **길고 말이 많아도 `none`일 수 있다.**

- 길 찾기, 주차, 차선, 주유·세차·계산 절차를 주고받는다.
- 어른끼리 일정, 장 볼 것, 돈 얘기 같은 용무를 의논한다.
- 물건을 찾고 건네고 닦는다.
- 형제가 자리·창문·간식으로 티격태격하고 어른이 말린다(화제가 서지 않는다).
- 질문에 단답만 돌아와 이야기가 서지 않는다.
- 스피커폰 업무 통화와 혼잣말.
- 내비 안내와 짧은 확인, 맥락 없는 조각, 긴 침묵.
- 다툼, 혼내기, 떼쓰기, 험담, 안 좋은 소식처럼 다시 보고 싶지 않을 대화(§5).

> "오늘 시험 어땠어" / "그냥" / "수학이 어려웠다며" / "응" / "저녁은 학원 끝나고 먹을 거지" / "어" — 다섯 번 오갔지만 받아서 이어 가는 사람이 없으므로 `none`이다.

## 5. 부정적인 대화는 남기지 않는다

**이야기가 잘 형성됐더라도, 나중에 다시 보고 싶지 않을 대화는 `none`이다.** 다투거나 안 좋은 얘기를 한 것을 다시 보고 싶어 하는 사람은 없다. 메모에 "부정"을 적어 따로 셀 수 있게 한다.

`none`으로 보는 것 (대화의 중심이 이것일 때):

- **다툼**: 부부나 가족이 서로 탓하고 언성을 높인다. 길을 잘못 든 것을 두고 진짜로 싸운다.
- **혼내기**: 성적, 숙제, 버릇을 두고 아이를 나무라고 아이가 대들거나 운다.
- **떼쓰기와 울음**: 아이가 울고 보채고 어른이 지쳐서 말린다.
- **험담과 불평**: 직장 사람, 친척, 이웃, 다른 운전자를 길게 욕한다.
- **안 좋은 소식과 걱정**: 병, 사고, 돈 문제, 누가 돌아가신 얘기를 무겁게 나눈다.

`keep`으로 남는 것:

- **장난스러운 놀림**: 웃으면서 주고받는 놀림과 티격태격. 분위기가 밝으면 남긴다.
- **지나간 일을 이야기로 하는 것**: 아이가 "오늘 친구가 내 모래성을 찼어" 하고 겪은 일을 들려주고 부모가 받아 준다. 속상한 일이 소재여도 지금 차 안의 분위기가 다투는 것이 아니면 `story`다.
- **잠깐의 투덜거림**: 이야기 중에 "아 막히네" 한마디가 끼는 것.

판단 기준은 **소재가 아니라 지금 차 안의 분위기**다. 헷갈리면 "이 사람들이 일 년 뒤에 이 장면을 다시 듣고 싶을까"를 묻는다. 실제 묶음은 목소리로 판단하고, 그래도 갈리면 `unsure`를 켠다.

## 6. 경계 사례

| 상황 | 판정 | 이유 |
| --- | --- | --- |
| 길을 잘못 든 것을 두고 부부가 서로 탓하며 언성을 높인다 | `none`, 메모 "부정" | 다툼이다 |
| 길을 잘못 든 것을 가족이 웃으며 놀린다 | `keep` / `moment` | 분위기가 밝다 |
| 성적 얘기가 길게 오가는데 부모가 나무라고 아이가 대든다 | `none`, 메모 "부정" | 여러 번 오갔어도 혼내기다 |
| 아이가 친구와 다툰 일을 들려주고 부모가 달래며 되묻는다 | `keep` / `story` | 소재는 속상해도 대화는 따뜻하다 |
| 할머니가 편찮으시다는 소식을 걱정스럽게 나눈다 | `none`, 메모 "부정" | 다시 듣고 싶은 장면이 아니다 |
| 돌아가신 할아버지와의 좋은 기억을 웃으며 떠올린다 | `keep` / `story` | 그리운 추억이다 |
| 형제가 웃으면서 서로 놀리다가 한쪽이 울음을 터뜨린다 | `none`, `unsure` | 끝이 울음이면 남기지 않는 쪽 |
| 이야기가 몇 줄 오간 뒤 화장실·길 찾기로 넘어가 길게 이어진다 | `keep` / `story` | 묶음 안에 이야기가 있다 (초안, DESIGN §12-2) |
| 용무와 내비뿐이다가 끝에서 이야기가 두세 번 오가기 시작한다 | `keep` / `story` | 위와 같다 |
| 여러 번 오가지만 전부 지금 할 일(주차 자리, 주차권)이다 | `none` | 화제가 아니라 절차다 |
| 부모가 화제를 여러 번 던지지만 단답만 돌아온다 | `none` | 받아 주는 사람이 없다 |
| 단답이 이어지다 한 화제에서 아이가 길게 말하고 부모가 되묻는다 | `keep` / `story` | 그 지점부터 이야기다 |
| 길을 잘못 든 것을 가족이 한두 마디 놀리고 끝난다 | `keep` / `moment` | 화제가 전개되지 않는다 |
| 놀림이 예전에 길 잃은 일 얘기로 이어져 서로 보탠다 | `keep` / `story` | 화제가 이어진다 |
| 질문에 답은 없지만 질문 자체가 웃음을 남긴다 | `keep` / `moment` | 한마디가 남는다 |
| 평범한 질문에 답이 없고 용무로 끊긴다 | `none` | 남는 것이 없다 |
| 아이가 혼자 길게 떠들지만 아무도 받지 않는다 | `none`, `unsure` | 말 자체가 재미있으면 `moment` |
| 일정 의논 중에 "그날이 할머니 생신이네" 하고 다시 일정으로 간다 | `none` | 용무의 일부다 |
| 일정 의논이 "작년 생신 때 케이크 엎었잖아"로 넘어가 주고받는다 | `keep` / `story` | 이야기가 생겼다 |
| 영상 시작 인사, 구독 요청, 내레이션 | `none`, 메모 "차 안 아님" | 탑승자 대화가 아니다 |

## 7. `policy` — 저장 차단

`keep` 판정과 무관하게 단다. 저장 차단은 앱의 규칙이 주로 맡고, 이 라벨은 규칙을 시험할 때 쓴다.

| 값 | 뜻 | 예 |
| --- | --- | --- |
| `optout` | 기록을 원치 않는다는 말이 있다 | "이 얘긴 남기지 말자", "지금 건 녹음하지 마" |
| `command` | 묶음이 기기 호출과 명령으로만 이루어져 있다 | "집으로 안내해 줘" |
| `external` | 탑승자의 말이 아닌 소리가 묶음의 대부분이다 | 라디오 사연, 스피커의 노래, 통화 상대 목소리 |

대화 중에 명령 한 줄이나 내비 안내 한 줄이 끼어든 것은 해당하지 않는다.

## 8. 자주 하는 실수

- **주고받았으니 이야기라고 본다.** 다툼과 혼내기도 여러 번 주고받는다. 분위기를 먼저 본다.
- **속상한 소재면 무조건 뺀다.** 지나간 일을 따뜻하게 들려주는 것은 남긴다.
- **길이로 판단한다.** 긴 묶음을 `keep`으로, 짧은 묶음을 `none`으로 보는 것. 긴 용무 얘기는 `none`이고 네 줄짜리 추억 얘기는 `story`다.
- **아이가 나오면 `keep`으로 본다.** 아이가 물 달라고 보채는 것은 `none`이다.
- **주고받은 횟수만 센다.** 절차를 열 번 주고받아도 `none`이다.
- **전사 글만 보고 판단한다.** 실제 묶음은 반드시 듣는다. 웃음과 말투는 글에 없다.
- **`story`와 `moment` 사이에서 오래 고민한다.** 둘 다 `keep`이다. 가까운 쪽을 고르고 넘어간다.

## 9. 출력 형식

사람 판정(청취 화면이 저장):

```json
{"id": "yt:VIDEO_ID@12", "keep": "keep", "kind": "story", "unsure": false, "policy": [], "comment": "", "listened": true, "labeler": "human:이름"}
```

합성 라벨(카드에서 옴):

```json
{"id": "synth:44@0", "verdict": "story", "pattern": "shared_memory", "boundary": false, "level": 1}
```

`verdict`가 `story`·`moment`이면 `keep`, `none`이면 `none`이다. 코멘트와 메모에 실제 전사 글을 옮겨 적지 않는다.
